# Iris Model API (FastAPI + Docker)

A minimal, production style example of deploying a scikit-learn machine learning model
behind a FastAPI REST API, containerized with Docker for environment consistency
and reproducibility.

This project demonstrates:
- ML model serialization with joblib
- API based inference using FastAPI
- Docker based deployment
- Common debugging and deployment practices

---

## Project Structure

```
ml-model-api-fastapi-docker
├── README.md
├── serving
│   ├── app
│   │   ├── main.py           # FastAPI app and routes
│   │   ├── model.py          # Request/response schemas
│   │   └── schemas.py        # Model + metadata loader
│   ├── Dockerfile        
│   ├── model
│   │   ├── metadata.json
│   │   └── model.joblib      # Trained ML pipeline
│   └── requirements.txt      # Model metadata (version, features)
├── training
│   └── train.py
└── TROUBLESHOOTING.md
```

---

## Prerequisites

- Python 3.11+ (for local execution)
- Docker Desktop (for containerized execution)

---

## 1) Train and Save the Model

```bash
python train.py
```

This generates:
- `model/model.joblib` — a trained scikit-learn Pipeline
  (StandardScaler + LogisticRegression)

---

## 2) Run Locally (Without Docker)

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Open API documentation:
- http://127.0.0.1:8000/docs

---

## 3) Run with Docker (Recommended)

### Build the image
```bash
docker build -t ml-model-api-fastapi-docker .
```

### Run the container
```bash
docker run --rm -p 8000:8000 ml-model-api-fastapi-docker
```

Open API documentation:
- http://127.0.0.1:8000/docs

If port 8000 is already in use:
```bash
docker run --rm -p 8001:8000 ml-model-api-fastapi-docker
```

---

## 4) Test the API

### Health Check
```bash
curl http://127.0.0.1:8000/health
```

Expected response:
```json
{ "status": "ok" }
```

### Prediction
```bash
curl -X POST "http://127.0.0.1:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{"features":[5.1,3.5,1.4,0.2]}'
```
